# Study & Code Planner

A daily study and coding planner for CSE students. It shows your timetable, tracks your progress, and gives you one task every day.

## Features
- Timetable for college days, home days and a weekly coding focus
- Live "Now" highlight on the current time slot
- Daily progress ring for academics and coding
- Streak counter with one rest day per week
- 12-week activity calendar
- One new task every day, rotating automatically
- Light and dark mode
- Progress saved in your browser, no sign-up needed

## Built with
HTML, CSS and vanilla JavaScript. No frameworks or build step.

## Run it locally
1. Download or clone this repository.
2. Open the folder in VS Code.
3. Right-click `index.html` and choose **Open with Live Server**.

## Customize
- Edit `SCHEDULES` in `script.js` to change your timetable.
- Edit `TASKS` in `script.js` to change the daily tasks.
- Edit the colors at the top of `style.css`.
